# Contributing to GrandMentor

Thanks for helping! Everything you need is in [`AGENTS.md`](AGENTS.md). It applies to humans and AI agents alike:

- **Branches:** branch from `dev` and open your pull request against `dev` (`gh pr create --base dev`).
- **Pull requests:** fill in [the template](.github/pull_request_template.md), including **"In plain words"**
  and a screenshot or GIF as evidence.
- **Quality gate:** run the checks listed under *Quality gate* in `AGENTS.md` before you open the PR.
  CI runs the same checks ([`tools/qa/README.md`](tools/qa/README.md) explains each one).
- **Conventions:** Rust, frontend, i18n and content rules are in `AGENTS.md`; the API contract is
  [`docs/CONTRACT.md`](docs/CONTRACT.md).
